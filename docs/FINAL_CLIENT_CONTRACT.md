# 最终版适配契约（2026-09-17）

## 范围与证据

只修改参赛系统；官方 06251432 与 0911 客户端保持原样。先比对文件 SHA-256 和托管程序集 IL，再验证实际接口。附件6规定 TCP + JSON，但没有提供端口、字段、分帧、客户端/服务器角色或确认机制；两个本地发行包均包含 LSLInletConfig.txt = EEGback|EEG。不能据此编造官方 TCP 协议或声称赛事联调成功。

## 实施边界

- EEG 接入地址和游戏输出配置严格分离，EEG 默认 127.0.0.1:8712。
- 以客户端实际代码核实 0/1/2/3 动作；四分类必须保留 left/right/forward/stop，不能把 rest 和 feet 都映射前进而丢失 stop。
- 官方 LSL 输出维持单通道 float32、EEGback|EEG、10 Hz，可用于局域网；接收者存在只证明订阅，不能当作车辆执行确认。
- 若提供 TCP JSON 适配，只能使用显式配置的协议参数；未知官方参数不设猜测默认值，不自动将自定义桥接器当成官方接口。
- 正式运行禁止人工控制 API 和离线回放；测试必须显式选择调试模式。自动停车不属于人工驾驶指令。
- 采集阻塞、推理异常、断流、重连与停止时输出 stop；恢复后使用完整新窗口，清除旧平滑历史。
- 独立发送节拍不受 EEG recv 阻塞影响；不缓存断线期间的驾驶指令。
- 日志区分模型判定、发送成功、接收订阅及未知执行状态。

## 验收映射

1. 文件/程序集差异：保留哈希清单、关键方法语义差异和配置内容。
2. 协议：实际 LSL inlet 接收四种命令；TCP 若启用用本地接收端测试完整字节与重连，明确这是模拟端。
3. 故障：断流/停机/推理异常发送 stop；恢复后等待新窗口；人工 API 默认拒绝。
4. 工程：Python 回归、模型 dry-run、前端构建、Rust 检查；能运行的 UI 进行实际交互验证。
5. 现场待验：真实 NeuSen W、第二台赛事电脑、防火墙与比赛网络、实际游戏状态和受试者闭环。缺少条件时明确记为未验证。
